# 一句话日记

每天用一句话,记下一天。手机优先、离线可用、无需账号,数据完全存在你自己的设备浏览器里。

## 功能

- **今天**:打开就写,一句话保存;已写过可随时更新或删除
- **日历**:按月浏览,写过的日子有圆点标记;点任意过去的日子可以补记
- **回顾**:连续记录天数、最长连续、累计天数与字数;「那年今日」会显示往年同一天写下的句子
- **备份**:一键导出 JSON 备份文件 / 导入合并 / 复制全部文字
- **安装**:作为 PWA 添加到手机主屏幕,全屏运行、离线可用
- 深色模式自动跟随系统;跨天自动刷新;不联网、不收集任何数据

## 在手机上使用(推荐)

本应用是纯静态网页,只要放到任何一个 HTTPS 静态托管上即可。

### 方式一:GitHub Pages(免费,长期稳定)

1. 在 GitHub 新建一个仓库(例如 `diary`),把本目录里的所有文件上传(`tools/` 可不传)
2. 仓库 **Settings → Pages → Branch** 选择 `main` / `(root)`,保存
3. 一分钟后,手机浏览器打开 `https://<你的用户名>.github.io/diary/`
4. 添加到主屏幕:
   - **iPhone(Safari)**:点分享按钮 → 「添加到主屏幕」
   - **Android(Chrome)**:右上菜单 → 「添加到主屏幕」或「安装应用」

### 方式二:Vercel / Netlify / Cloudflare Pages

把本目录拖进 Vercel(netlify)的部署页面即可,几十秒拿到一个 `https://xxx.vercel.app` 地址。

### 方式三:局域网临时使用

电脑上在本目录运行 `python -m http.server 8000`,手机连同一 Wi-Fi,访问 `http://<电脑IP>:8000`。
(仅适合临时体验;安装 PWA 和离线缓存需要 HTTPS 或 localhost。)

## 数据与备份(长期使用必读)

- 所有日记保存在**这台设备的浏览器本地存储**里,不上传、无账号、无网络请求
- 风险:清除浏览器数据、卸载浏览器、恢复出厂会**丢失数据**
- 因此请养成备份习惯:**设置(右上角)→ 导出备份**,每 1~3 个月一次,导出的 JSON 建议存到云盘 / 微信收藏
- 换新手机:先在新手机打开网站 → 设置 → **导入备份** → 选择旧备份文件(合并式导入,新旧内容都保留,同一天以较新的为准)
- 设置页会显示「上次备份」时间,超过 60 天未备份会变红提醒

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 全部功能都在这一个文件里(样式+逻辑) |
| `manifest.webmanifest` | PWA 应用信息(名称、图标、主题色) |
| `sw.js` | Service Worker,负责离线缓存 |
| `icon-*.png` / `apple-touch-icon.png` | 应用图标(源图为 `tools/logo-source.png`) |
| `tools/make-icons.ps1` | 重新生成图标(Windows PowerShell;想换 logo,替换 `tools/logo-source.png` 后重跑) |

## 常见问题

- **直接双击 index.html 能用吗?** 基本能用,但无法安装到主屏幕、无离线缓存;iOS 下数据更容易被系统清掉。长期使用请部署到 HTTPS。
- **换了浏览器/换了手机数据还在吗?** 浏览器本地存储按「域名+浏览器」隔离,同一手机换浏览器数据不互通,用导入备份迁移。
- **想改样式?** 全部颜色变量集中在 `index.html` 顶部 `:root` 里,改完刷新即生效。
- **以后更新了这个应用,手机上怎么生效?** 改完把 `sw.js` 第一行 `CACHE = 'yijuhua-v1'` 的版本号改成 `v2`、`v3`…,手机重新打开两次即可(旧缓存会自动清理)。
